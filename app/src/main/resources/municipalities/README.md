`kyushu-2026-09-26-v1.tsv` はUTF-8の固定マスター。列は通信コード、
e-Stat標準地域コード（5桁）、県名、市町村名。通信コードはアプリ独自であり、
公式コードの下位バイト・末尾桁ではない。初版のみ公式コードの昇順で1から採番した。
0および234–255は未割当で拒否する。政令指定都市は北九州市・福岡市・熊本市を
市単位で含める。区・郡・県そのものと沖縄県は対象外。
e-Statの市区町村欄が空の政令市は「政令市・郡・支庁・振興局等」欄を採用。
通知地点名は県名と市町村名を結合し、例として `福岡県北九州市` を保存する。

再現手順：出典URLの `page` を1〜12に替えたHTMLを `.gradle/municipalities-N.html`
へ保存し、リポジトリルートで `./tools/import-municipalities.ps1` を実行する。
件数、重複、各県件数を検証してマスターを出力する。このスクリプトは初版の再現専用。

更新時は既存通信コードを再採番・再利用しない。追加は未割当コードから割り当てる。
廃止コードは予約し、名称変更も含めてバージョンを更新する。256枠に収まらなくなったら
通信形式の変更が必要。既存DBの生存情報との互換性・移行を設計せずに表を置換しない。
履歴の地点名スナップショットは後から書き換えない。

受信APIは相手のマスターバージョンを必須とし、不一致・未指定なら保存前に拒否する。
バージョンのBLEハンドシェイクは後工程で実装する。通信コードの意味が異なる相手から
バージョンを推測したり、ローカル値を代入して受信を通したりしない。
